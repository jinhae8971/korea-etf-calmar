# Narrative Radar

크립토 내러티브 상대강도 관측 + 변화 탐지.

## 이 시스템이 하는 일
고정된 내러티브-종목 매핑에 대해 매일 측정한다.
- 30/7/1일 BTC 대비 초과수익 **중앙값** (섹터 대표값)
- 구성종목 확산 **폭** (BTC를 이긴 종목 비율)
- 거래 **회전율**(volume/mcap)과 그 횡단면 z
- 위 지표들의 **순위 변화**를 이력으로 누적

## 하지 않는 일
미래 수익률 예측. 이 지표들은 사전 검증된 예측력이 없다.
점수는 "지금 자금이 어디에 반응하는가"에 대한 서술일 뿐이다.

## 설계 원칙
1. 관측기이지 예측기가 아니다.
2. `universe.json` 매핑은 고정한다. 성과를 보고 갈아끼우면 사후선택 편향.
3. 섹터 대표값은 평균이 아닌 중앙값. 평균은 소수 극단치가 지배한다.
4. 수집 실패 시 "변화 없음"을 절대 발송하지 않는다. "판정 불가"로 명시한다.

## 구조
- `narrative_radar.py` — 수집·계산·탐지·렌더 (stdlib only)
- `universe.json` — 고정 매핑 (변경 시 frozen_at + changelog 갱신 필수)
- `data/latest.json` — 최신 스냅샷. `message` 필드에 렌더된 텔레그램 본문 포함(릴레이가 그대로 전달)
- `data/history.json` — 일별 순위·폭·도미넌스 이력 (최근 400일)
- `tests/` — 유닛 테스트 23개

## 실행
```
python narrative_radar.py            # 오늘
python narrative_radar.py 2026-08-21 # 특정일 라벨
```
환경변수: `PAGES_URL`, `DASHBOARD_DIR`, (선택) `TELEGRAM_TOKEN`/`TELEGRAM_CHAT_ID`

## TVL 괴리 (v2)
가격 추세와 예치금(TVL) 추세의 이탈을 `가격변화 − TVL변화`(%p)로 측정한다.
- 체인 → `/v2/historicalChainTvl/{chain}` (일별 시계열 → 7일·30일 즉시)
- 프로토콜 → `/protocols` 1회 (change_7d). 상위 브랜드는 parentProtocol 자식을 TVL 가중 합산,
  그래도 없으면 `/tvl/{slug}` 현재값 폴백. 30일은 자체 누적 이력으로 약 30일 후부터 채워진다.
- $20M 미만 풀은 제외(소형 풀은 %변화가 쉽게 폭발한다).
- **TVL은 펀더멘털이 아니다.** 예치금일 뿐이며 인센티브 파밍으로 부풀고 중복 계상된다.
  프라이버시·DePIN·오라클은 TVL 개념이 무의미하므로 `llama` 필드를 비워 계산 대상에서 제외한다.

## 괴리 발굴 — 전체 시장 스캔 (v4)
`discovery.py`. universe.json과 **무관하게** DefiLlama 전체에서 gecko_id가 붙은 체인·프로토콜을 훑는다.
v1에서 Monad가 누락된 실패(고정 목록에 없으면 원리적으로 안 잡힘)에 대한 구조적 대응이다.

찾는 것(LAGGING = Monad형): TVL은 늘었는데 가격이 안 따라온 종목
- TVL 증가 ≥ 20%(30일) 또는 ≥ 10%(7일)
- 괴리(가격−TVL) ≤ -15%p
- MC/TVL ≤ 1.5, 30일 가격 ≤ +50%, 24h 거래대금 ≥ $1M

거르는 것(전부 코드로):
- 30일 증가분의 60% 이상이 하루에 발생 → 고래 예치·인센티브 개시로 보고 제외
- 유통량 적은 신규 토큰의 MC/TVL 착시 → FDV/TVL 병기
- 하루 반짝 등장 → 2일 이상 유지된 것만 알림으로 승격(`data/discovery_state.json`)

반대 방향(HOT = 과열): TVL은 빠지는데 가격만 오른 종목도 참고용으로 함께 보고.
조건 충족 종목이 없으면 침묵하지 않고 스캔 수와 주요 탈락 사유를 표기한다.


## v5 — 회전율 z를 자기이력 기준으로 전환 (2026-09-06)

**문제.** 종목점수의 25%를 차지하는 회전율 z가 *횡단면* z였다. 회전율은 종목 고유
성질(원래 거래가 활발한 코인은 계속 활발하다)이라, 이 항목의 전일 대비 지속성이
0.934로 z7(0.855)보다도 높았다. 가중치의 25%가 사실상 상수로 굳어 순위 갱신을
둔화시켰다. 17일치 실측에서 top5 전일 유지가 3.62/5였다.

**조치.** 회전율 z를 *자기이력* 기준으로 바꿨다.

    z = (오늘 회전율 − 과거 30일 중앙값) / (1.4826 × MAD)

- 중앙값·MAD를 쓰는 이유: 회전율은 꼬리가 두꺼워 과거 스파이크 한 번이 평균·표준편차
  기준선을 부풀리고 이후 신호를 죽인다.
- 오늘은 기준선에서 제외한다(look-ahead 차단).
- 시장 전체가 한산해지면 전 종목 z가 동시에 내려가므로 횡단면 중앙값을 빼 상대 척도로
  맞춘다. z30·z7이 횡단면 정규화라 척도를 일치시켜야 한다.
- 상한 ±3.0. 캡 민감도 실측(2.5/3.0/4.0/5.0 → top5 전일유지 3.12/2.94/2.88/2.81)에서
  기준선이 아직 짧아 MAD가 불안정한 점을 고려해 보수적으로 택했다.
- 종목별 이력이 8일 미만이면 0(중립). 전체의 70% 미만이 산출되면 구방식(횡단면)으로
  폴백하고, 두 방식을 섞지 않는다(스케일이 달라 순위가 왜곡됨).

**이력 시딩.** v5 이전 스냅샷에는 종목별 회전율이 없다. 과거 latest.json 17일치에서
역추출한 `turnover_seed.json`을 동봉하고, history의 빈 날만 채운다(기존 값은 덮어쓰지
않음). 이후로는 매일 스냅샷의 `turn` 필드에 누적된다.

**효과(17일 재계산).** top5 전일 유지 3.62 → 2.94. 30일 수익률은 밋밋하나 평소 대비
거래가 급증한 종목(STRK·ASTER 등)이 새로 포착된다. 반대로 회전율이 원래 높아 상시
상위였던 종목의 자동 가산점은 사라진다.

**한계.** 여전히 관측기이지 예측기가 아니다. 회전율 급증은 자금 유입의 흔적일 뿐
방향을 말하지 않는다. 상한 ±3에 걸린 종목들 사이의 순서 정보는 소실된다.
