# Binance Alpha Trend Radar

바이낸스 **알파 마켓** 상장 토큰 중 *차트 구조*와 *수급*이 동시에 정렬된 종목을 선별해
GitHub Pages 대시보드 + 텔레그램(전략비서 채널)으로 매일 보고한다.

## 무엇이 아닌가

- **예측기가 아니다.** 점수는 "지금 자금이 어디에 반응했고, 그 자리가 차트 구조상 어디인가"의
  서술이다. 미래 수익률을 주장하지 않는다.
- 알파 마켓은 유동성이 얕고 **에어드랍 포인트 파밍성 거래**가 섞여 있다. 거래량 기반 지표가
  실수요를 과대평가할 수 있어 `회전이상(WASH_SUSPECT)` 플래그를 병기한다.

## 데이터 원천 (전부 공개·무인증)

| 용도 | 엔드포인트 |
|---|---|
| 알파 토큰 전체 목록(가격·시총·유동성·홀더·상장시각) | `www.binance.com/bapi/defi/v1/public/wallet-direct/buw/wallet/cex/alpha/all/token/list` |
| 종목별 캔들 | `/bapi/defi/v1/public/alpha-trade/klines?symbol=ALPHA_xxxUSDT` |
| 벤치마크(BNB) | `data-api.binance.vision/api/v3/klines` |

실측 메모
- `api.binance.com` 은 러너/컨테이너 IP에서 **HTTP 451(지역차단)**. 반드시 `data-api.binance.vision` 을 쓴다.
- `www.binance.com` 이 막힐 경우를 대비해 `www.binance.info` 를 폴백 호스트로 둔다(`www.binance.me` 는 503).
- klines 는 알파 CEX 오더북이 있는 토큰만 제공된다. 없는 토큰은 `-1121 Invalid symbol` 로 응답 →
  차트 판정 대상에서 제외(실측 105종목 중 7종목).
- 캔들의 taker-buy 필드는 전체 거래량과 동일한 값이 들어온다 → **매수우위 지표로 사용 불가**(실측 확인).

## 파이프라인

1. **유니버스** — 고정목록이 아니라 규칙으로 매 실행 재구성(알파는 회전이 빨라 고정목록은 신규 상장을 원리적으로 누락).
   `offline/delisted` 제외 → 유동성 ≥ $200K, 24h 거래대금 ≥ $300K, 시총 ≥ $3M → 일봉 20개 이상.
   상장 21일 미만은 **신규 관찰 트랙**으로 분리(추세 판정에서 제외).
2. **차트 지표(일봉, 미완성 봉 제거)** — 7·30일 수익률, EMA20/50 정렬, 60일 고점 근접도,
   로그가격 추세 R², 20일 신고가, ATR 압축도(돌파 직전 구간으로 측정), 거래대금 5일/20일 확장.
3. **수급 지표** — 회전율(24h거래대금/시총), 유동성/시총, 홀더·유동성 증감(자체 이력 누적, 7일 시차),
   유통비율, 포인트 이벤트 여부.
4. **테마** — 이름·심볼 키워드 규칙(`themes.json`)으로 10개 테마 태깅. 미매칭은 `UNTAGGED` 로 남기고
   중립 적합도를 준다(잔여집합의 중앙값이 점수를 왜곡하지 않도록).
5. **점수** — `(0.60×차트 + 0.40×수급) × 테마적합(0.55~1.00) × 리스크감점`.
   횡단면 정규화는 **중앙값·MAD 로버스트 z**(크립토 극단치가 평균·표준편차를 지배하는 문제 회피).
   테마 적합도는 곱이 아니라 가중혼합이라 **점수의 부호를 뒤집지 못한다**.
6. **리스크 감점** — 회전이상(회전/유동성 ≥100) ×0.70, 유동성<$500K ×0.80, 유통비율<30% ×0.85,
   30일 +300% 초과 과열 ×0.70.
7. **승격 규칙** — 상위 10에 **2일 이상 연속** 남은 종목만 텔레그램 "추세 후보"로 승격한다.
   하루 반짝 뜬 종목은 알림으로 올리지 않는다.
8. **변화 감지** — `BREAKOUT`(20일 신고가+거래대금 1.5배), `RANK_JUMP`(5계단↑),
   `HOLDER_SURGE`(홀더 +10%), `TOP10_ENTRY/EXIT`.

## 실패 처리

- 차트 데이터 0건 → `FAILED` + **exit 1**. "이상 없음"을 보내지 않는다.
- 커버리지 70% 미만 → `DEGRADED` 표기.
- `HTTP 451` 은 재시도하지 않고 지역차단으로 즉시 진단한다.

## 파일

```
alpha_radar/
  alpha_radar.py      엔진(수집·지표·점수·이벤트·렌더링)  — stdlib only
  themes.json         테마 키워드 규칙 + 스크리닝 임계
  tests/test_radar.py 유닛테스트 30개
  data/               latest.json · history.json(90일) · state.json(연속일수)
```

`DOCS_DIR` 환경변수를 주면 그 경로에 대시보드 `index.html` 을 쓴다.
