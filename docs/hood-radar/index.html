검증: 표본 8건 — 판정 유보
표본 8건(최소 10건) — 판정 유보. 스냅샷이 더 쌓여야 한다.
순위 급등 종목의 이후 24시간 시총 변화에서 유니버스 중앙값을 뺀 초과수익을 측정합니다. 결과가 음(-)이나 무의미로 나와도 그대로 표기합니다 — 이 시스템이 매수 신호로 오독되지 않게 하는 것이 이 측정의 목적입니다.

데이터 건전성

2차 소스(DexScreener) 대조 — 판정 OK · 대조 6종 · 중앙 괴리 0.51% · 최대 괴리 3.42%. 8% 초과 시 해당 종목에 SRC_DIVERGENCE를 답니다.
DexScreener 유료 프로모션 등재 5종 — 홍보 집행 신호이며 품질 보증이 아닙니다.

읽는 법과 한계

· 관측기이지 예측기가 아닙니다. 순위와 변동은 "지금 자금이 어디에 반응하는가"의 서술이며 미래 수익률을 주장하지 않습니다.
· 시총 기준 — MC는 유통시총, FDV는 완전희석시총. 교차체인 브릿지 토큰은 타 체인 시총이 섞여 들어오므로 FDV로 대체하고 BRIDGED_MC로 표시합니다.
· 토큰 식별은 컨트랙트 주소로 합니다. 이 체인은 동일 티커 카피캣이 다수 존재해 심볼로는 구분되지 않습니다(COPYCAT 플래그).
· 제외 대상 — 스테이블·랩드 토큰, 토큰화 주식/ETF(Robinhood Token 표기 또는 CoinGecko id 접미사로 판별). 티커만 겹치는 코인을 오제외하지 않기 위해 티커 목록만으로는 제외하지 않습니다.
· 편입 규칙 — 유동성 ≥ $25K, 24h 거래대금 ≥ $50K, 시총 ≥ $300K를 모두 충족하면 자동 편입됩니다. 고정 목록이 아니므로 신규 상장분도 다음 실행에 잡힙니다.
· LIQ_THIN / LIQ_DRAIN / YOUNG / SINGLE_POOL은 러그풀·허니팟 개연성이 높은 조건입니다. 진입 전 컨트랙트와 유동성 락을 직접 확인하십시오.
· 컨트랙트 검증은 GoPlus(chain 4663) 기준입니다. LP 락 비율은 이 체인에서 전 종목 0%로 관측되는데, 락커 컨트랙트를 스캐너가 인식하지 못하는 것일 수 있어 "락 없음"이 아니라 확인 불가로 봅니다.
· 미색인은 안전이 아니라 검증 불가입니다. 신생·소형일수록 색인되지 않습니다.
· 소급 이력(source=ohlcv_backfill)은 현재 공급량을 과거에 그대로 적용해 재구성한 값이라, 추가발행·소각이 있었다면 왜곡됩니다. 실측 스냅샷이 우선합니다.
· 데이터: GeckoTerminal 공개 API(온체인 DEX 집계) + DexScreener 교차검증 + GoPlus 보안. 수집 실패 시 "판정 불가"로 표기하며 정상 브리프를 발송하지 않습니다.
