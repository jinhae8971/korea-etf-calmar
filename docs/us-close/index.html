  • 엔비디아 실적(장 마감 후): 매출 1,158억 달러(+103%), 데이터센터 1,076억 달러(+110%), 총이익률 74.9%였어요. 4분기 가이던스는 1,300억 달러(±3%, 1주 추가, 중국 데이터센터 매출 제외)예요. 크레스 임시 CEO는 '베라 루빈이 폭발적으로 출발했다'고 했어요.
