## 판정

| 신호군 | 무엇을 | 경보 조건 (예) |
|---|---|---|
| S1 온체인 | LIT 이동, 신규 컨트랙트, RH체인 공급 | 풀 규모 이동·신규 컨트랙트 수령·공급 급증 |
| S2 공식 | 문서·공식 글(텔레그램·블로그·X·앱 공지) | 새 문장에 전환·청구·종료 단어 + 토큰 맥락 / TGE·청구 날짜가 적힌 공식 글 |
| S3 앱 | 프론트 번들·JS·API 응답 | 청구·보상 화면 신규 / 청구 API가 404에서 실제 값으로 / 빈 필드에 값 등장 |
| S4 보조 | 뉴스·Polymarket | 관찰까지만 |

등급: **조용함 → 관찰 → 경보 → 임박**. 임박은 서로 다른 근거(온체인·문서·공식 글·리더보드·앱) 2종이 7일 안에 경보이거나,
공식 글이 TGE·청구를 날짜와 함께 말할 때. 거래소마다 따로 판정하고, 한 실행의 메시지는 하나로 묶는다.
새 거래소·새 원천은 첫 실행에 기준선만 잡는다(시딩). 핵심 원천 절반 미만 수신이 2회 연속이면 잡 실패.

키워드: 'airdrop·TGE·tokenomics' 같은 강한 단어는 그대로, 'distribute·allocation·claim·launch' 같은 단어는 같은 문장에
토큰 맥락(token·티커·에어드랍)이 있을 때만, 'ended·concluded'는 포인트·토큰 맥락이 있을 때만 잡는다.
API 토큰·액세스 토큰처럼 토큰이 아닌 'token'은 맥락으로 치지 않는다.

## 메시지 (outbox — 실행마다 많아야 하나)

- **경보·임박**: 거래소 · 무슨 일(새 문장 원문 + 잡힌 단어) · 의미 · 해제 조건 · 원문·대시보드 링크.
- **정정·해제**: 보낸 경보가 풀리면 한 번 — 오탐이면 정정, 해제 조건이면 해제.
- **감시 범위 변경**: 거래소를 더하거나 뺄 때 한 번 — 다가오는 일정 · 거래소별 지금 상태 · 수집 상태 · 토큰 출시 확률.
- **현황**: 요청할 때 — `request.json`의 `summary.id`를 새 값으로 push(`at` KST, `note`는 첫 줄 문구)하거나 Actions에서
  `perp-dex-radar` 수동 실행(`summary` 켬). 다른 메시지가 없을 때, 낮에만 — 못 하면 다음 낮 실행. 24시간 지난 요청은 버린다.
- **월간 점검**: 월초 7일 안 첫 낮 실행, 경보가 없을 때.

요약 메시지(범위 변경·현황·월간 점검)는 거래소 칸 사이를 빈 줄로 띄우고, 굵게는 챙길 것에만 쓴다 (2026-10-24 "거래소간
줄바꿈해서 가시성을 올려주고 강조할게 있으면 표시도 해줘"): 3일 안 일정 · 7일 안 마감 · 설정 문구에서 `**`로 감싼 핵심 사실 ·
토큰 출시 확률 70% 이상 · 수집 일부 실패. 경보·임박은 🟡·🔴로 표시한다. `key_dates`는
`{"at": "YYYY-MM-DD[ HH:MM]", "until"?: 마감, "label"?: "11월 중"처럼 날짜 미정(at = 늦어도), "text"}`(KST) — 90일 안, 안 지난 것만.

`latest.json`의 `outboxes`는 24시간 안에 만든 메시지 전부(오래된 순)다. 실행이 몰려 메시지가 연달아 바뀌어도 중계가 놓치지 않는다.

## 문서 감시 규칙 (2026-10-22·10-24 오탐 뒤 보강)

- 키워드는 단어 경계로만 잡고, 원래 있던 문장을 조금 고친 것은 관찰로 낮춘다(체크박스·날짜 추가는 예외).
- GitBook 'Agent Instructions'·Mintlify 안내문은 본문에서 뺀다. '페이지 없음'이면 기준선을 덮지 않고 문서 목록에서
  같은 파일 이름(없으면 같은 제목)으로 새 주소를 찾아 따라간다(`doc_moves`). 못 찾으면 관찰 '찾을 수 없음'.
- 문서 목록은 새로 생긴 페이지만 본다 — 주소만 옮긴 페이지는 신호가 아니다.
- 규칙을 고치면 지난 문서 경보도 매 실행 다시 판정한다(`judge.rejudge`). 오탐으로 풀리면 정정 메시지가 나간다.
  10/24 08:10 LRH 경보('distributed' — 토큰 언급 없는 포인트 설명)가 이렇게 풀려 범위 변경 메시지에 정정으로 붙는다.
