# Optical Radar — 광통신 · 메모리 · 나스닥 상대강도 + 광통신 과열 게이지

호스트 레포 `korea-etf-calmar` 의 서브디렉터리(`optical_radar/`)로 배포된다. 스톡봇(`STOCK_BOT_TOKEN`) 채널로 평일 KST 07:07 발송.

- 소스: `optical_radar.py` (표준 라이브러리만), 유니버스: `universe.json`
- 데이터: `data/prices.json`(1y 일봉 캐시, Yahoo 실패 시 폴백) · `data/latest.json` · `data/history.json`
- 대시보드: `docs/optical-radar/` → https://jinhae8971.github.io/korea-etf-calmar/optical-radar/
- 실행: `python optical_radar.py [YYYY-MM-DD] [--dry-run] [--force]`
- 멱등: 같은 `as_of`(미국 종가일)는 재발송·재커밋하지 않는다.

## 패턴 규칙 (정량)
파라볼릭(50MA 이격 상위 5% + 가속) · 거래량 클라이맥스(5/60 ≥1.8x + 진폭 ≥1.5 ATR) · 블로우오프 후보(클라이맥스 + 윗꼬리) · 갭업 연속(5일 중 3일) · RSI 하방 다이버전스 · 200일선 극단 이격(상위 3%)
